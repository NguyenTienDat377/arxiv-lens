How it works

A graph that refuses to ship when it shouldn't.

  1. 01 · extract

    Ontology-constrained

    Six entity types and six relations, open-coded from the corpus. Edges that break domain or range are repaired when the ontology forces one answer, reported when it doesn't.

  2. 02 · gate

    Drift blocks promotion

    If the extractor changes its answers on papers that can't have changed, the build exits non-zero. A corpus moving into new topics is reported, not blocked.

  3. 03 · prove

    Checked by Z3

    The assembled graph goes to an SMT solver, which finds contradictions no single paper contains and returns the minimal set of facts behind each.

  4. 04 · answer

    Traverse, then cite

    A question becomes an intent, its phrases link to nodes, and the answer is a traversal, with an arXiv ID behind every claim.

Graph vs. vector

"Unrelated" is an answer.

Vector search always returns its top k, even when nothing is relevant. arxiv-lens tells three outcomes apart, and the empty ones count as findings.

  • STATUS_ENTITY_NOT_FOUNDThe phrase matched nothing in the graph. You get a no, not a guess at the nearest neighbour.
  • STATUS_NO_FACTSBoth ideas exist, but no paper in the corpus connects them. That's the finding.
